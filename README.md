# 麦记 · 营养手账

> 写日记的时候，顺手把今天吃的那顿麦当劳记进去。
> 单文件网页 · 零依赖 · 双击就开 · 营养数据接麦当劳 MCP

---

## 一句话

**点餐助手解决「买什么」，麦记解决「吃完之后」。**

大多数人吃完麦当劳，对今天摄入了多少热量没有任何概念。而写日记的人，恰好有「记录」的习惯——只差一个把两件事接起来的动作。麦记做的就是这件事：在你的 Markdown 日记里，多一个「今日餐盘」面板，选几样，自动算出热量和三大营养素，一键写成表格塞进日记。

数据来自麦当劳 MCP 服务（`list-nutrition-foods` 等工具）。没有 Token 时自动退回离线快照，界面会明确标出数据来源，不会让人误以为是官方实时值。

---

## 它和已有的点餐类作品有什么不同

| | 常见点餐助手 | 麦记 |
|---|---|---|
| 解决的问题 | 帮你**买**（推荐、下单、比价） | 帮你**记**（吃完之后的营养归档） |
| 产出 | 一个订单 | 一段留在日记里的 Markdown |
| 用完之后 | 关掉就没了 | 一年后还能翻回去看「那天我在学校吃的什么」 |
| 联网 | 必须联网 | 离线也能写日记，联网只是刷新数据 |

麦记不是点餐工具，它是**饮食记录工具**，只是数据源接了麦当劳。

## 快速开始

### 方式一：只想看看（10 秒，不需要任何配置）

双击 `mc_ji.html`。

浏览器直接打开，内置离线演示数据，所有功能都能点。顶部会显示「○ 离线演示快照」。

### 方式二：接真实麦当劳 MCP 数据（约 3 分钟）

1. **申请 Token**：打开 <https://open.mcd.cn/mcp> → 右上角登录 → 控制台 → 激活 → 复制 Token
2. **设置环境变量**

   ```bat
   :: Windows CMD
   set MCD_MCP_TOKEN=你复制到的token
   ```

   ```bash
   # macOS / Linux
   export MCD_MCP_TOKEN=你复制到的token
   ```

3. **跑一次同步**

   ```bash
   python tools/sync_nutrition.py
   ```

   看到 `来源=mcp` 就成功了。重新打开 `mc_ji.html`，顶部会变成「● 麦当劳 MCP 实时」。

> 只需要 Python 3.9+，**不用装任何第三方包**。`tools/mcd_mcp.py` 是纯标准库写的 MCP 客户端。

### 常用命令

```bash
python tools/sync_nutrition.py --dry       # 只看会拉到什么，不改文件
python tools/sync_nutrition.py --offline   # 恢复离线演示数据
python tools/mcd_mcp.py check              # 只测连通性，列出全部工具
```

## 功能

### 1. 今日餐盘（主体功能）

- 左侧列出餐品（名称 + 热量），点「+」加入
- 右侧实时累计 **热量 / 蛋白质 / 脂肪 / 碳水 / 钠**，带进度条
- 超过每日参考值 80% 变黄，超过 100% 变红
- 自动累计花费金额
- 底部显示手上的优惠券

### 2. 一键写入日记

点「写入日记」，自动生成这样的 Markdown，插入到日记正文并切换过去：

```markdown
### 今日餐盘 2026-10-22

| 餐品 | 热量 | 蛋白质 | 脂肪 | 碳水 | 钠 |
| --- | --- | --- | --- | --- | --- |
| 巨无霸 | 550 kcal | 25.0 g | 30.0 g | 42.0 g | 950 mg |
| 薯条（中） | 340 kcal | 4.0 g | 16.0 g | 44.0 g | 250 mg |
| **合计** | **890 kcal** | **29.0 g** | **46.0 g** | **86.0 g** | **1200 mg** |

- 花费合计：¥37.0
- 数据来源：麦当劳 MCP 实时数据

> 营养参考值按一般成人估算（2000 kcal / 蛋白质 60 g / 脂肪 60 g / 碳水 300 g / 钠 2000 mg），不构成医疗或营养建议。
```

### 3. 原有的手账能力（全部保留）

- Markdown 语法教学（分条卡片 + 实时渲染对照）
- 编辑器 + 实时预览双栏
- 10 个格式按钮（标题 / 粗体 / 斜体 / 列表 / 引用 / 代码 / 代码块 / 表格 / 分隔线）
- 导出 `.md`，可自选保存文件夹
- 草稿自动缓存；「放弃草稿」不留下任何痕迹
- 手机端适配（工具栏横向滚动、单列布局）
- 深色模式跟随系统

## 用到了哪些麦当劳 MCP 工具

| Tool | 用途 | 是否必须 |
|---|---|---|
| `list-nutrition-foods` | 拉餐品的能量、蛋白质、脂肪、碳水、钠 | 是 |
| `query-meals` / `query-meal-detail` | 补充餐品名称与分类（可选） | 否 |
| `query-my-coupons` / `available-coupons` | 显示手上的券与有效期 | 否 |
| `calculate-price` | 校验价格（可选） | 否 |

详细调用流程、字段映射与容错策略见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)。

## 目标用户

- **记饮食的学生**：食堂 / 快餐为主，想知道「这顿到底多少卡」但懒得用专门的 App
- **有写日记习惯的人**：日记里本来就会写「今天吃了什么」，麦记让这句话变成可统计的数据
- **减脂期但离不开快餐的人**：先看清楚，再决定要不要加个圣代
- **想学 Markdown 的人**：边写边学，写完还能导出 `.md`

## 技术说明

| 项 | 方案 |
|---|---|
| 形态 | 单个 HTML 文件（内联 CSS + JS + 数据） |
| 前端依赖 | **零**。无 CDN、无框架、无构建步骤 |
| Markdown 渲染 | 自写解析器（标题 / 加粗 / 斜体 / 列表 / 引用 / 代码块 / 表格 / 分隔线 / 图片 / 链接） |
| 配色 | OKLCH 纸感手账风，衬线标题，跟随系统深色模式 |
| 数据注入 | 营养数据内嵌为 `<script type="application/json">`，由 Python 脚本刷新 |
| 为什么内嵌 | `file://` 下 `fetch()` 会被浏览器按 CORS 拦掉。内嵌才能保证**双击就能用** |
| MCP 客户端 | `tools/mcd_mcp.py`，纯标准库实现 Streamable HTTP + JSON-RPC，支持 SSE 响应 |
| 存储 | 草稿与餐盘都存 `localStorage`，不上传任何服务器 |

## 已知限制（说清楚比藏起来好）

1. **离线演示数据是近似值**，不是官方实时结果。要真实数据请配 Token 跑同步。
2. **营养字段名做了多路容错**，但麦当劳随时可能调整返回结构。若某天同步失败，`data/raw_nutrition.json` 会留下原始返回，方便对照修 `normalize_item()`。
3. **不提供医学建议**。参考值是一般成人估算，个体差异很大。
4. **不做下单**。这是记录工具，下单请用官方 App 或别的作品。
5. **餐品列表来自 MCP 返回**，本地不维护硬编码菜单（除了演示快照那一份）。
