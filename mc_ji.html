md 文件是什么？

.md 就是 Markdown 文件：用普通文本写带格式的内容（标题、列表、加粗、表格…），任何电脑都能打开，永远不会“坏档”。写完还能转成网页、PDF。

  • 写日记、笔记、文档、说明手册都在用它
  • GitHub、知识库、程序员的 README 全是 md
  • 本页右侧预览的格式，就是你的文本渲染后的样子
